DroidVM

Your virtual computer. Anywhere.

DroidVM is a powerful Android application designed to run virtual machines and operating systems directly on your Android device.

Run Linux distributions, Windows and other compatible operating systems in a virtual environment. Import system images, configure virtual hardware and enjoy a desktop experience right on your smartphone or tablet.

Developed by Astrix Tech.

📦 Image Formats

DroidVM is designed to support common virtual machine image formats:

Format| Purpose
ISO| Operating system installation media
IMG| Disk images
QCOW2| QEMU virtual disks
RAW| Raw disk images

Import images using the Android file picker.

DroidVM prepares compatible images and allows users to configure virtual machines.
